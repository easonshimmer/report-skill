# 工作报告生成 Skill

一个用于生成专业职场汇报的 Codex Skill。安装后，提供工作事项即可生成日报、周报、月报或年报；结果数据和接下来的方向均为可选。

## 文件

- `SKILL.md`：技能定义和报告生成规则。

## 输入方式

直接描述报告周期，以及你做了什么。以下信息按需补充：

| 信息 | 是否必需 | 示例 |
| --- | --- | --- |
| 报告类型 | 建议提供 | 日报、周报、月报、年报 |
| 做了什么 | 必需 | 完成客户访谈，推进新版本上线，处理线上反馈 |
| 结果数据 | 可选 | 访谈 8 位客户；版本按期上线；反馈处理率 95% |
| 接下来的方向 | 可选 | 整理访谈结论，跟进遗留问题 |

不需要先整理成表格，零散要点也可以。若日期、受众、字数或格式有要求，一并说明。

## 使用示例

### 日报

```text
帮我写一份日报：
做了什么：完成支付流程回归测试，和设计确认了空状态方案，修复了 3 个高优先级问题。
结果数据：测试了 42 条用例，通过 39 条，另外 3 条被接口问题阻塞。
接下来的方向：明天跟进接口修复并完成剩余回归。
```

### 周报

```text
整理成周报：
做了什么：推进新用户引导改版；完成 5 场用户访谈；协助销售准备产品演示。
结果数据：引导页已发布，访谈发现 2 个主要流失原因。
接下来的方向：下周确定优化优先级并启动第一项改进。
```

### 月报或年报

```text
请根据下面内容写一份月报，面向部门负责人，控制在 500 字以内：
做了什么：……
结果数据：……
接下来的方向：……
```

## 输出原则

- 按报告周期组织内容，默认使用简体中文和简洁、客观、专业的语气。
- 突出工作进展、成果和下一步，避免流水账和空泛套话。
- 不编造数据、日期、贡献、完成状态或业务影响；没有量化数据时如实作定性总结。
- 用户提供模板、受众、语言或篇幅要求时，按要求生成。

## 安装

将本仓库作为一个 Skill 使用，或将仓库目录复制到 Codex 的 skills 目录中，并确保目录内包含 `SKILL.md`。安装完成后，可通过描述报告任务或显式调用 `work-report` 使用。
